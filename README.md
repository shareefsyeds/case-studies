# Case studies

Write-ups of systems I've built and run on an internal platform used by 200+ people at a clinical-trial technology company. There's no company code here, and internal products are described by what they do.

| Case study | What it covers | Status |
|---|---|---|
| [From custom code to low-code workflows](low-code-workflows.md) | A visual workflow engine with 50 step types and Teams approvals. A real flow was built in 15 minutes with no code. | Live |
| [Turning 250+ internal APIs into AI tools with MCP](mcp-gateway.md) | MCP tools generated from OpenAPI specs plus a curated set, with authorization kept in the apps | Live |
| [A reusable app template with 13 integration adapters](app-template.md) | Sign-in, roles, audit log and adapters for every new app. An invoicing app on it serves 100+ users. | In use |
| [Contractor timesheets with real-time Snowflake sync](contractor-timesheets.md) | Replaced a weekly batch with real-time sync to Snowflake and Certinia, built with two colleagues | Live |
| [A document assistant on Bedrock](document-assistant.md) | Retrieval-augmented answers over internal documents, in the web app and Microsoft Teams | Pilot |
| [An AI agent team with human approval](ai-agent-team.md) | AI plans and drafts code changes. A person approves the plan and merges the result. | In development |
| [Platform foundations](platform-foundations.md) | Self-service apps, observability, credential vault, shared packages, the move to Amazon EKS and a CloudWatch cost finding | Live |

The full portfolio is at [shareefsyeds.github.io](https://shareefsyeds.github.io).
